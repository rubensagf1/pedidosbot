# PedidoBot – IA de Atendimento para Delivery via WhatsApp

## 🚀 Como Rodar o Projeto

1. Clone o repositório e entre na pasta:
```bash
git clone https://github.com/seuprojeto/pedidobot
cd pedidobot-app


Instale as dependências:
pip install -r requirements.txt
Configure as variáveis de ambiente no arquivo .env:

Coloque suas informações:
WHATSAPP_TOKEN=seu_token_do_cloud_api
WHATSAPP_PHONE_ID=id_do_numero_telefone

Rode o servidor:
python app.py

Acesse o site:
http://127.0.0.1:5000
